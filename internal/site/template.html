Getting the files

Open a magnet link in any BitTorrent client. A folder model is a single torrent that recreates the Hugging Face repository layout in one directory (a BitTorrent client names that directory after the revision; point vLLM or SGLang at it). Each magnet carries a Hugging Face web seed, so the download starts immediately even with zero peers on the swarm.

Or point a running viiwork-parrot node at a model and let it do the rest:

models:
  want: [{{if .Models}}{{(index .Models 0).ID}}{{else}}model-id{{end}}]

It downloads every file, verifies each sha256, and starts seeding automatically. Source and setup instructions live at {{.RepoURL}}.
